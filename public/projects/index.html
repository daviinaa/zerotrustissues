GAN-Based Fraud Detection Pipeline

MSc dissertation: an automated CI/CD pipeline that deploys a GA-GAN credit card fraud classifier (adapted from Ge et al., 2025) to Azure Kubernetes Service. Every push to main runs the unit tests (91% coverage) and a model evaluation gate (AUC, F1, precision and recall thresholds) before a SHA-tagged image is rolled out, health-checked and rolled back automatically on failure. Predictions were identical across local, minikube and AKS for all 56,962 test transactions, and AKS held a 15 ms median latency at 100 concurrent users. Training stays manual; Prometheus and Grafana for monitoring.
