# Personal site

Plain static HTML in `public/`, deployed to Cloudflare Pages by GitHub Actions.
Open a pull request to get a preview; merging to `main` deploys production.

New post: copy an existing `public/articles/<slug>/index.html`, then add it to
`public/articles/index.html`, the home page's recent writing (if one of the 3 newest)
and `public/sitemap.xml`.
